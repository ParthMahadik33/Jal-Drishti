# JalDrishti — Urban Flood Intelligence

> **See the risk. Fix the cause.**  
> Citizen reports and flood insights that help cities understand recurring waterlogging and act sooner.

## Overview
JalDrishti is an urban flood intelligence platform combining citizen crowdsourced reporting with predictive flood analysis to empower municipal decision-makers and resilient urban communities.

## Features
- **Editorial Hero Interface**: High-aesthetic climate-tech hero landing page with curated typography (Instrument Serif & Manrope).
- **Interactive Water-Eye Mascot**: Mouse-scrubbed interactive animation controlled smoothly by horizontal cursor movement and touch dragging.
- **Responsive Layout**: Designed for wide screens, desktops, tablets, and mobile devices.
- **Fast & Modern Stack**: React 19, TypeScript, Vite, and Tailwind CSS.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm / pnpm / yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/ParthMahadik33/Jal-Drishti.git
cd Jal-Drishti

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
